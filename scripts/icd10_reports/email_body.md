## **What has changed?**

[There is a new **multi-edition ICD-10 OpenSAFELY release** on OpenCodelists](https://opencodelists.org/docs/#icd10-editions). This combines the ICD-10 editions used in NHS hospital admissions data and ONS mortality data into a single release, allowing the same codelist to be used more reliably across these OpenSAFELY datasets. We've also incorporated a number of structural improvements that have added codes and helpful information were not available in the previous OpenCodelists ICD-10 release.

Existing ICD-10 codelists have **not** been changed automatically, so the versions previously used in OpenSAFELY studies remain unchanged.

## **What does this mean for your codelists?**

We've identified that one or more of your ICD-10 codelists created using the previous OpenCodelists ICD-10 release (see below) would contain different codes if they were created with the new release, which is why we're contacting you today.

This email describes codelists that you have created yourself but if you are using, or have used, codelists created by someone else you will receive a separate email with details of those codelists.

## **Review your relevant codelists**

We've prepared a personalised report showing the ICD-10 codelists we've identified as requiring review.

From the report, you can open each codelist directly in OpenCodelists and create an updated version using the new ICD-10 OpenSAFELY release.

Most affected codelists can be updated with minimal changes. Where a code has different meanings or descriptions between ICD-10 editions, OpenCodelists will clearly highlight it and explain the decision you need to make.
